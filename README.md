# Sales Forecasting Dashboard

## Project Overview
This project predicts and analyzes retail sales using Machine Learning and provides an interactive dashboard using Streamlit.

## Technologies Used
- Python
- Pandas
- Plotly
- Streamlit
- Scikit-Learn

## Machine Learning Models
- Linear Regression
- Random Forest Regression

## Features
- Sales Analysis Dashboard
- Monthly Sales Trend
- Sales by Category
- Sales by Region
- Top 10 States
- Top 10 Products
- Payment Mode Analysis
- Interactive Filters

## Model Performance

Linear Regression
- R² Score: 0.20
- MAE: 248.76

Random Forest
- R² Score: 0.58
- MAE: 155.96

## Run Project

```bash
streamlit run dashboard.py
```
